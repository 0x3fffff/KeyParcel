# KeyParcel 虚拟键盘中文输入

在 KeyParcel 主界面切换到虚拟键盘后，点击「安装中文输入」。如果还没装小狼毫，请从[上游发布页](https://github.com/rime/weasel/releases/tag/0.17.4)下载 `weasel-0.17.4.0-installer.exe`，放进本目录，再点击按钮。安装时选择「简体中文」。安装结束后，KeyParcel 会把扩展导入已启用的方案，并重新部署。已有小狼毫时，按钮直接导入。修改现有方案配置前会保留一份 `.keyparcel.bak`。检测到扩展已部署后，按钮会隐藏。

KeyParcel 会核对未修改的小狼毫 0.17.4 官方安装包的 SHA-256。许可证和对应源码可在[上游发布页](https://github.com/rime/weasel/releases/tag/0.17.4)查看。

如果提示某个方案需要手动合并，按下面的步骤操作。

1. 安装 [小狼毫](https://github.com/rime/weasel/releases/tag/0.17.4)，安装时选「简体中文」，并在 Windows 输入法列表中启用它。
2. 从小狼毫菜单打开「用户文件夹」，把本目录的 `lua/keyparcel_input.lua` 复制到用户文件夹的 `lua` 子目录。
3. 在当前小狼毫方案的 `<方案 ID>.custom.yaml` 中添加下方配置。例如「朙月拼音·简化字」对应 `luna_pinyin_simp.custom.yaml`。文件已存在时，将该行合并到现有 `patch:` 下，保留其它配置。如果已有同名路径，请用另一个插入位置保留两项。

```yaml
patch:
  "engine/processors/@before 0": lua_processor@*keyparcel_input
```

4. 选择小狼毫的「重新部署」。如果启用了多个方案，为希望使用的方案各加一次同样的配置。

回到 KeyParcel 启用虚拟键盘。在记事本等普通文本框里按原来的快捷键试输 `不会吧。不会吧 A1`。含中文的文字会临时启用小狼毫，扩展确认就绪后逐字提交原文。完成、暂停、切走窗口或遇到错误时，KeyParcel 会尝试恢复原来的 Windows 输入法。小狼毫内原先选中的拼音方案无需更换。纯半角英文仍使用原有的美式键盘输入路径。
