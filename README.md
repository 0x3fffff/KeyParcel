# KeyParcel

Windows 局域网文字接力工具。手机打开网页发送文字，电脑按全局快捷键把文字打到当前输入框。

## 全屏应用怎么用

使用学习通、iTest 等全屏应用时，如果当前活动允许查阅资料，可以让电脑留在全屏界面，用手机搜索资料。把选好的文字发到 KeyParcel，再回到电脑的输入框按快捷键粘贴。能否输入取决于目标窗口是否接受 Windows 模拟按键。

## 快速开始

1. 启动 KeyParcel，点「连接手机」。手机和电脑接入同一可信局域网。
2. 选择与手机同网的地址，点「开启接收」。首次使用时扫二维码配对。Windows 如果询问是否允许访问，只在可信的专用网络启用。
3. 手机发出文字后，在目标输入框按 **Ctrl + Shift + V**。最近一条手机文字可以反复使用，收到新文字后更新。没有手机文字时使用电脑剪贴板。
4. **Ctrl + Alt + V** 直接使用电脑剪贴板。输入时再按一次启动本轮粘贴的快捷键，可以暂停。切换窗口也会自动暂停。
5. 回到原窗口并把光标放回输入框，按 **Ctrl + Alt + Shift + V** 从断点继续。暂停后按任一粘贴快捷键，会读取该来源的最新文字并开始新一轮。三组快捷键均可修改，Ctrl + V 留给当前应用。

字符间隔支持 0 至 250 毫秒。0 表示最快。开始或继续输入前留出约 500 毫秒。退出程序会清除手机文字及本轮粘贴进度，配对和快捷键仍会保存。电脑地址变化后请生成新配对码。

## 快捷文本

点击主窗口的「管理快捷文本」打开独立窗口。新增条目后填写标题和正文，点击「保存条目」。新增条目优先分配空闲的 `Ctrl+1` 至 `Ctrl+9` 和 `Ctrl+0`，之后依次尝试带 Shift、Alt 的数字组合。按键可以自行修改。删除条目只释放它的按键，下次新增时可以补用。

打开「启用快捷文本」并关闭编辑窗口，就可以在其他应用中按对应快捷键输入。总开关、条目内容和按键保存在本机，重启后恢复。快捷文本沿用字符间隔、同键暂停和原窗口续输。保存有内容的条目后，开启总开关会占用它绑定的全局按键，例如 `Ctrl+1`。

接收通过局域网 HTTP，默认使用 TCP 8765。端口被占用时，KeyParcel 会自动选择一个可用端口，并用新端口生成访问地址和二维码。若手机提示需要重新配对，在电脑点「生成新配对码」，再用手机扫码。建议在可信网络中使用。访客 Wi-Fi 可能隔离设备，防火墙也可能需要放行专用网络。目标应用是否接受模拟按键，取决于应用和运行权限。

## 构建

在 Windows PowerShell 或 PowerShell 7 中运行 `./Build.ps1`。生成 `dist/1.4.1/KeyParcel.exe`。构建使用 Windows 本机的 .NET Framework 编译器。手机网页和应用图标内嵌在 EXE 中。

配置保存在 `%LOCALAPPDATA%/KeyParcel`，退出应用并删除该目录可清除配对和个人设置。
